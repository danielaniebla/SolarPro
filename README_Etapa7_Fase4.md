# SolarPro 8.5 · Visor de cartografía documental de CFE

Se añade acceso directo y visor integrado opcional de la figura III.1 del Programa de Ampliación y Modernización de las Redes Generales de Distribución 2024–2038 (CFE), página 7. El visor requiere internet y el servidor de CFE puede bloquear la incrustación; el enlace al PDF funciona como alternativa cuando el servidor está disponible. El mapa no se vectoriza ni se infieren polígonos.

Se conservan el catálogo de 16 divisiones, el recorrido interactivo, el simulador y los módulos previos. La visualización se carga solo tras pulsar el botón, por lo que no afecta el funcionamiento sin conexión del resto de la aplicación.

Fuente: https://beta.cfe.mx/distribucion/cumplimiento/Documents/PAM%20RGD%202024-2038%20VF.pdf
