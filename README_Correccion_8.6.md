# SolarPro 8.6 · Corrección de error HTTP 502

Se eliminó el iframe externo de CFE, que mostraba error HTTP 502 en el navegador. Se sustituyó por una cuadrícula local interactiva de las 16 divisiones documentadas, vinculada al catálogo ya existente. Las tarjetas no son polígonos ni posiciones geográficas. El enlace al documento original permanece como referencia externa opcional, sujeto a disponibilidad del servidor. No se pudo verificar una copia local de la figura oficial y no se ha simulado su imagen.

Se conservan los módulos previos, el mapa contextual, el recorrido y el simulador.
